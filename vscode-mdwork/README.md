# MDWork Markdown Preview

A VS Code preview extension using MDWork's own Markdown block/inline parser and HTML renderer.

## Use

1. Install the `.vsix` through **Extensions → … → Install from VSIX…**, or run `code --install-extension MDWork-vscode-1.0.0.vsix`.
2. Open a Markdown file.
3. Open the Command Palette and run **MDWork: Open Preview**.

The preview supports common Markdown, GFM tables/task lists/strikethrough, code highlighting, Mermaid flowcharts, MDWork compact headings, local and remote images, and MDWork image wrapping with clear blocks. Local images are restricted to the document directory. HTTP, HTTPS and Mailto links open externally.

This extension is a live preview. Use the MDWork desktop application for document management, image importing and styled PDF export.

Full manuals: `docs/user-guide.zh-CN.md` and `docs/user-guide.en-US.md` in the MDWork source distribution.
